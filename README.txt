CISCM COMPLETE WEBSITE DESIGN — 27 PAGES

OPEN THE SITE
Extract this ZIP, then open index.html in a browser. Internal pages are linked locally.
Alternatively open the separately supplied CISCM_Complete_Website.html: all pages are embedded in one file and require no internet connection.

EDIT THE SITE
Edit individual .html pages in a text editor. Shared colors, layout, navigation and footer styles are in assets/theme.css. Shared navigation and draft-form behavior are in assets/site.js. The six previously designed pages also have their own CSS and JavaScript in assets/.
After editing, run python3 build_standalone.py from this folder to rebuild standalone.html and standalone-source.txt. This helper uses only the Python standard library.

- Searchable domains, services and FAQs
- Interactive credential, membership, proficiency, review-outcome and process tabs
- Expandable standards and FAQs
- Draft contact, membership, accreditation and verification forms
- Draft text download and mailto links (visitor chooses whether to send)

STATIC DESIGN LIMITS
No backend, authentication, payment service, email submission, file upload service or live credential registry is connected. Forms prepare local drafts only. No message is sent by preparing or downloading a draft. Selected files are not uploaded or embedded; attach manually after confirming the route. A live production site needs approved submission, privacy, security and records arrangements.

CONTENT ITEMS FOR REVIEW
- The source privacy page identifies a different organization. A review-required privacy page is included instead of treating that text as CISCM policy.
- The source accessibility and verification URLs returned 404 errors. The included accessibility page is a proposed information layout, not a WCAG certification. Verification prepares an enquiry; it does not search a register.
- The source Body of Knowledge download link led to credentials, rather than a document. The new design routes document requests to contact.
- The source program application link opened the institutional form. The design uses program enquiries to confirm the route.
- Duplicate renewal and complaint-process sections were consolidated.
- Published recommended periods and scoring remain labelled as recommendations.
- Existing accreditation, assessment and membership requirements must be confirmed with CISCM before production publication.
- The six original redesigns are included with unified navigation, footer and local links. Their prior separate files were not modified.
